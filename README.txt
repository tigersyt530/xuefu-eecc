學扶練習小站 × 教師題庫 v0.1
解壓縮整份 ZIP，保留 papers 資料夾、data.js 與 index.html 在同一層。用 Chrome / Edge 開啟 index.html。
75 組 111–115 年國語、數學、英語原卷及答案卷，1875 筆初步題號索引。112 年缺國語及數學一、二年級，以及英語三年級。
數學三至六年級的紅色選項擷取為暫定答案，尚未逐題人工核對；其他答案可從教師端參照原答案卷填寫。分類只是關鍵字初步標籤，不等同官方細目。低年級手寫題、閱讀題組與英文聽力必須參照原卷及官方評分方式。英語音檔請自行從原上傳 ZIP 選取。
教師端可選題、修改答案與分類、匯出 CSV、列印原卷頁面（會包含同頁其他題）。學生端可作答、查看暫定評分與錯題。紀錄僅存本機瀏覽器，並非正式評量。尚未提供跨裝置同步、單題精準裁切、官方細目完整對照、Word 組卷及 QR code。
若需公開部署，請先確認教育部試題的使用授權，且不要收集學生姓名等個資。

v0.2 錯題學習中心：交卷後可查看原卷、作答、參考答案、觀念解說、原題重練與類題。115 年資料夾四年級數學卷先提供 18 題逐題解說及自編類題；原卷頁尾標示 114 年，年度仍沿用上傳資料夾，請教師確認。其餘題目教師可在選題端展開編輯解說、錯因與類題。答案未全面核對，錯因只是可能性。學習狀態與編輯存在本機；延後再測為相隔至少一天的同一類題。尚未提供完整逐題裁切、所有題目解析、跨裝置同步或全面瀏覽器測試。
